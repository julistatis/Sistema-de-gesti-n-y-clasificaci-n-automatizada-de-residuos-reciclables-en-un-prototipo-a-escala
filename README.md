# Sistema-de-gesti-n-y-clasificaci-n-automatizada-de-residuos-reciclables-en-un-prototipo-a-escala
Proyecto académico que utiliza sensores, una banda transportadora y un ESP8266 para clasificar residuos en plástico, metal, vidrio y orgánicos, demostrando una alternativa automatizada para mejorar los procesos de reciclaje y aprovechamiento de materiales.

Descripción del proyecto

Este proyecto consiste en el diseño y construcción de un prototipo a escala para la clasificación automatizada de residuos reciclables, tomando como referencia la problemática de los residuos sólidos en la localidad de Kennedy. El sistema representa etapas como el ingreso del residuo, transporte mediante una banda, lectura de sensores, procesamiento de datos, clasificación, desvío con servomotores, depósito, conteo y monitoreo. Las categorías de clasificación son plástico, metal, vidrio y orgánico. Además, se incluye una etapa demostrativa para el aprovechamiento del plástico mediante la transformación de botellas PET en hilo reutilizable. El proyecto integra mecánica, electrónica, programación y organización de procesos, con el objetivo de demostrar el funcionamiento de una alternativa automatizada para la clasificación de residuos y evaluar sus posibilidades de mejora.

Sensores Utilizados

Sensor Inductivo

Detecta materiales metálicos.

TCS3200

Identifica características relacionadas con el color.

HX711 + Celda de carga

Mide el peso del residuo.

DHT11

Registra humedad ambiental.

Proceso de Clasificación

  1. Ingreso del residuo.
  2. Transporte mediante banda.
  3. Lectura de sensores.
  4. Procesamiento de datos en ESP8266.
  5. Clasificación.
  6. Activación de servomotores.
  7. Depósito en contenedores.
  8. Conteo y monitoreo.

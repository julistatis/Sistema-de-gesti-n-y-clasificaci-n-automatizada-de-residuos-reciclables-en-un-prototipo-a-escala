SISTEMA DE GESTIÓN Y CLASIFICACIÓN AUTOMATIZADA DE RESIDUOS RECICLABLES EN UN PROTOTIPO A ESCALA

Caso de aplicación: Localidad de Kennedy, Bogotá

Descripción del proyecto

Este proyecto consiste en el diseño y construcción de un prototipo a escala para la clasificación automatizada de residuos reciclables. El sistema utiliza una banda transportadora, sensores y un ESP8266 para identificar y clasificar residuos en plástico, metal, vidrio y orgánicos. Además, incorpora funciones de conteo, monitoreo y una etapa demostrativa para el aprovechamiento del plástico.

Sensores Utilizados

🧲 Sensor Inductivo

Detecta materiales metálicos.

🌈 TCS3200

Identifica características relacionadas con el color.

⚖️ HX711 + Celda de carga

Mide el peso del residuo.

💧 DHT11

Registra humedad ambiental.

Proceso de Clasificación

  1. Ingreso del residuo.
  2. Transporte mediante banda.
  3. Lectura de sensores.
  4. Procesamiento de datos en ESP8266.
  5. Clasificación.
  6. Activación de servomotores.
  7. Depósito en contenedores.
  8. Conteo y monitoreo.
